# M1 战斗目标与验收

> 版本：v1.0 · 2026-09-23  
> 对照：`第0-1章节拍.md`、垂直切片验收表、用户反馈（画面/界面/技能过简/缺智斗）  
> 状态：替换「演示脚手架」为 M1 战斗目标；**不是**把 VS 黄方块当成品

---

## 一句话目标

M1 战斗要让玩家感到：**看得懂、点得顺、每回合有取舍、情报能改变打法**——仍是纯回合箱庭，不做战棋。

---

## In Scope（必须交付）

### A. 画面演出（可读，非过场大片）
- 战斗场景有明确战场底（墓穴氛围，非纯色块演示房）
- 敌我有可读立绘/精灵位（64×64 或战斗用剪影升级版均可；占位须过「一眼分清敌我与动作」）
- 受击、异能释放、胜利各至少 1 套可读反馈（闪白/震屏/简单 FX 可）

### B. 整体界面
- 指令面板中文可读：攻击 / 技能 / 防御（或等价）
- 常驻：己方 HP、异能共鸣槽、失控条、敌方 HP（及情报状态见下）
- 键位提示常驻或首回合教学一次；禁止只靠无说明的 J/K 演示键当终局方案

### C. 技能 ≥2～3，有取舍（建议默认包）
| 技能 | 效果方向 | 代价 / 取舍 |
|------|----------|-------------|
| 普通攻击 | 稳定伤害，无额外风险 | 低收益 |
| 异能共鸣·脉冲 | 高伤 / 清杂 | 消耗共鸣；推高失控 |
| 异能共鸣·洞察（或等价） | 本战揭示弱点 / 情报推进 | 低伤或无伤；占行动 |
| （可选第 3）防御 / 蓄力 | 减伤或下回合强化 | 牺牲本回合输出 |

> 数值可调；验收看「敢不敢用异能」与「要不要先洞察」，不看数值是否终局。

### D. 智斗钩子（M1 只做 1 条主钩，做透）
**选定：情报 / 弱点**（与第1章 Beat02/06 对齐）

- 未收集情报：敌方信息为 `???`，弱点不可见
- 战斗中可通过「洞察」类技能，或战前/战后观察，把情报推到「部分 → 完整」
- 完整情报后：UI 显示弱点；打弱点有可读收益（伤害加成或打断一次危险动作）
- 精英战 / 守护者框架战至少 1 次「先摸情报再打」比盲打更顺的体验

### E. 遭遇覆盖（与 M1 清单对齐）
- 杂兵战：练手感与情报教学
- 精英「死骸骑士」：至少 1 次阶段变化（血量阈值或行动模式切换即可）
- 第一守护者：框架战——可进、可战、可出胜/败/认可占位结果；**不要求**完整交涉树

## 技能与属性克制薄片（M1）

> 状态：已锁定（数值与 id 不改）。本节是 In Scope C「技能取舍」与 D「情报 / 弱点」的最小可玩落地。  
> 显示术语用：异能共鸣、失控、认可；文件名与 id 保持英文。

### 属性（3 种）
| id | 显示名 | 克制 |
|----|--------|------|
| `physical` | 物理 | 克 咒术 |
| `arcane` | 咒术 | 克 暗影 |
| `shadow` | 暗影 | 克 物理 |

- 克制环：物理 → 咒术 → 暗影 → 物理
- 伤害倍率：打克制方 **×1.5**；被克制时 **×0.75**；其余 **×1.0**

### 技能（5 个）
| id | 显示名 | 属性 | 定位 | 失控 |
|----|--------|------|------|------|
| `attack` | 攻击 | 物理 | 普攻 | 基本不推 |
| `slash` | 斩击 | 物理 | 战技 | 基本不推 |
| `arcane_bolt` | 咒弹 | 咒术 | 魔法；消耗异能共鸣 | 推高 |
| `deep_echo_pulse` | 异能脉冲 | 暗影 | 魔法 | 明显推高 |
| `insight` | 洞察 | 无属性 | 本场战斗内揭示敌人弱点属性 | 不推 |

### 规则
- 只有 `arcane` 和 `shadow` 类技能推失控条
- 咒弹消耗异能共鸣，默认消耗 20（`data/skills.json` 的 `resonance_cost`）
- 洞察只在本场战斗内生效：敌情 `???` 换成揭示后的弱点属性，战斗结束即失效
- 弱点收益先只做伤害加成（即上表 ×1.5）

### 验收（可勾选）
- [ ] 1. 战斗指令里能选到战技和魔法，5 个技能按钮都在
- [ ] 2. 洞察后用克制属性打，伤害明显高于盲打（按 ×1.5 可见）
- [ ] 3. 咒弹和异能脉冲会推高失控，攻击和斩击基本不推

### Out（放 M2）
- 完整技能树
- 4 种以上属性
- 状态异常
- 弱点以外的收益

## 精英与守护者战规则（M1）

> 状态：已锁定（2026-09-29，数值为默认值，F5 后可调 json）。落地 In Scope E「精英阶段变化 / 守护者框架」，只沿用「技能与属性克制薄片（M1）」的 3 属性、5 技能、×1.5 / ×0.75。  
> 不加新技能、新属性、状态异常。弱点只按敌人当前 `element` 用 `TurnManager.get_weakness()` 推导，不另设弱点字段。

### 通用：敌人出招数据（`data/enemies.json` 新增字段）
| 字段 | 类型 | 说明 |
|------|------|------|
| `moves` | dict | 招式表，键为招式 id；字段沿用 skills.json 的 `name` / `damage_min` / `damage_max`，蓄力招另有 `telegraph`（预告文案） |
| `rotation` | array | 按顺序循环出招的招式 id；取代现有 `_do_enemy_turn()` 里写死的 5–12 伤害 |
| `phases` | array | 阶段列表（只有精英用）；每阶段可覆盖 `element` / `attack` / `sprite` / `rotation` |
| `sprite` | string | 战斗立绘路径（res://assets/art/characters/enemies/…） |

- 敌招不吃属性倍率（玩家没有属性）；`attack` 只作显示或兜底，实际伤害以招式 `damage_min/max` 为准
- 蓄力招：出招当回合 0 伤害，并弹出 `telegraph` 预告；下一个 `rotation` 位固定是对应的大招

### 1. 精英「死骸骑士」`death_knight`（第1章 Beat08 · 第1层·精英战场）
| 项 | 第 1 阶段「咒缚铠甲」 | 第 2 阶段「暗影本体」 |
|----|----------------------|----------------------|
| 触发 | 开战 | 首次 `hp ≤ max_hp × 0.5`（默认 ≤ 70），且当下未死（`phases[1].hp_ratio_trigger`） |
| HP | `max_hp` = 140 | **不重置**，接着扣 |
| 属性 → 弱点 | `arcane` → 弱 **物理** | `shadow` → 弱 **咒术** |
| 被克制 | 暗影（异能脉冲 ×0.75） | 物理（攻击、斩击 ×0.75） |
| `attack`（显示） | 9 | 12 |
| 招式 `rotation` | 横斩 → 横斩 → 举剑蓄力 → 碎骨重击（4 回合一轮） | 暗影斩 → 举剑蓄力 → 深渊重击（3 回合一轮） |
| 立绘 `sprite` | `enemy_death_knight_combat_idle_p1_00` | `enemy_death_knight_combat_idle_p2_00` |

| 招式 id | 显示名 | 伤害 | 备注 |
|---------|--------|------|------|
| `knight_cleave` | 横斩 | 7–11 | 第 1 阶段 |
| `knight_charge` | 举剑蓄力 | 0 | `telegraph`：「死骸骑士高举巨剑……下回合将发动重击！」 |
| `knight_crush` | 碎骨重击 | 20 | 第 1 阶段大招 |
| `shadow_cleave` | 暗影斩 | 10–14 | 第 2 阶段 |
| `abyss_crush` | 深渊重击 | 26 | 第 2 阶段大招（蓄力沿用 `knight_charge`） |

**换阶段规则（智斗钩）**
- 在玩家行动结算后判定。换阶段那一刻：`enemy.element` 改为 `shadow`；换立绘；`rotation` 从头开始
- **打断蓄力**：骑士正在蓄力时被打进第 2 阶段，这次重击取消。这是阶段规则，不算弱点收益，让玩家可以卡血线化解大招
- **情报作废**：敌情回到「情报: ???」，弱点图标隐藏。可以再洞察，也可以看伤害飘字 / 日志颜色自己判断（克制是金色 `#C9A24A`，被克制是灰色 `#7A8B9A`）
- 表现：居中横幅加战斗日志「铠甲崩裂——死骸骑士的暗影本体苏醒了！」，配一次闪白或震屏。**不用**认可 Toast，免得和认可混淆
- 建议加信号 `enemy_phase_changed(phase: int)`（TurnManager 发出，combat_ui 收到后重置情报、换图）

**数值预期（默认值，可调）**：第 1 阶段用物理打大约 4 回合。第 2 阶段洞察一次再打 3 发咒弹（27×3），大约 4 回合，玩家总共挨 70–90 伤害，能赢。第 2 阶段如果不洞察、继续用物理（每下约 6–12），要 7 回合以上，大概率输。狂按异能脉冲（中性 25）也能速推，但失控会冲到 90 以上。

### 2. 守护者战框架：「第一守护者·死者统领」`undead_overlord`（第1章 Beat11→12 · 第3层）
**进入**：先在 Beat11「第3层·守护者殿前」的魂灯（`save_point_ch1_guardian`）存档，写入 `guardian_1_ready = true`。之后和守护者大门交互（CombatTrigger，`enemy_id = "undead_overlord"`），弹出确认「踏入守护者殿堂？」，确认后开战。没有 `guardian_1_ready` 时门不响应。

| 项 | 默认值 | 字段 |
|----|--------|------|
| HP | 160 | `hp` / `max_hp` |
| 属性 → 弱点 | `physical` → 弱 **暗影**（咒弹被克制 ×0.75） | `element` |
| 出招 | 死灵弹 7–11 → 死灵弹 → 墓咏蓄力（0，有预告）→ 墓葬新星 20，循环 | `moves` / `rotation` |
| 胜档认可点 | +10 | `recognition_value`（沿用现有结算） |
| 认可判定 | 见下表 | `recognition_rule.*` |
| 立绘 | `enemy_undead_overlord_combat_idle_00` | `sprite` |

**认可条件**（`recognition_rule`，只在守护者 HP **首次** ≤ `max_hp × hp_ratio_window` 的那次结算判定一次）
| 条件 | 默认 | 字段 |
|------|------|------|
| 本场用过洞察 | 必须 | `require_insight: true` |
| 本场打中弱点（`effectiveness == "advantage"`）的次数 | ≥ 3 | `min_weakness_hits: 3` |
| 本场从未失控（`player.overload` 从未到 `max_overload`=100） | 必须 | `forbid_overload: true` |
| 判定窗口 | HP ≤ 30%（≤ 48） | `hp_ratio_window: 0.3` |
| 认可档奖励 | +30 认可点 | `recognition_bonus: 30` |

- 设计意图：M1 里骑士第 1 阶段弱物理、第 2 阶段弱咒术，守护者弱暗影，三种攻击属性各有一个用武之地。守护者的弱点正好是最推失控的异能脉冲（每次 +30），3 次命中约 +90，贴着 100 的线，想拿认可就得算着放，这是认可档的核心取舍
- TurnManager 每场记录 `combat_stats = {insight_used, weakness_hits, overloaded}`，开战时清零
- 只判一次、判完窗口就关：拖回合刷不出认可，HP 就那么多，弱点命中次数也有上限。条件不满足时，日志 / 横幅显示「死者统领：……仅此而已吗。」，战斗继续，最后只能是胜或败

**三档判定（互斥，按优先级从高到低；每次行动结算后判定）**
| 优先级 | 结果 | 条件 | 之后 |
|--------|------|------|------|
| 1 | 认可 `recognized` | 判定窗口打开的那次结算里，认可条件全部满足（即使这一下正好打到 0 也算认可） | 守护者停手，战斗结束；弹认可 Toast，标题「守护者的认可」，文案（占位）「……住手。你看穿了我的本质，却没被力量吞噬。」+30 |
| 2 | 胜 `win` | 守护者 `hp ≤ 0`，且没有触发认可 | 普通胜利结算 +10 |
| 3 | 败 `lose` | 玩家 `hp ≤ 0` | 回最近的魂灯重来 |

- 胜 / 认可之后：回到探索，守护者触发器隐藏，提示「第1章 完成」（M1 终点，Beat12 之后的节拍 M2 再做），然后**自动存档一次**（`checkpoint_ch1_complete`），让结果写进存档
- 败之后（精英战败也一样）：`SaveManager.load_game()` 读单槽存档，回到最近存过档的魂灯位置，恢复存档时的 HP 和失控值。精英对应 Beat05 中继祭坛，守护者对应 Beat11 殿前魂灯。触发器不隐藏，可以重打

### 存档 flag（本节写入）
| flag | 类型 | 写入时机 | 值 |
|------|------|----------|----|
| `elite_corpse_knight_defeated` | bool | 死骸骑士战胜利 | `true`（沿用节拍 / flag 文档里的现有名字） |
| `guardian_1_result` | string | 守护者战结算 | `"win"` / `"recognized"` / `"lose"`（败：读档后写入内存，下次存档时才落盘） |
| `guardian_1_defeated` | bool | 胜或认可 | `true`（flag 文档里的含义是「守护者战完成」） |
| `guardian_1_recognition` | int | 胜或认可 | 胜 = `1`，认可 = `2`；败不写（保持 `0`）；`3` 留给 M2 交涉 |
| `chapter_1_complete` | bool | 胜或认可 | `true` |
| `player_data.recognition` | int | 胜或认可 | 胜 +10，认可 +30（现有字段，累加） |

### 验收（可勾选）
- [ ] 1. 打死骸骑士，HP 降到一半时出现「铠甲崩裂」横幅，立绘换成第 2 阶段图，HP 不回满
- [ ] 2. 换阶段后敌情变回「情报: ???」；再洞察一次，显示的弱点从「物理」变成「咒术」
- [ ] 3. 第 2 阶段用斩击或攻击打，日志是灰色「被克制」；用咒弹打是金色「克制！」，伤害明显更高
- [ ] 4. 骑士「举剑蓄力」时有预告，下回合打出重击；蓄力时把它打进第 2 阶段，这次重击不会打出来
- [ ] 5. 守护者战：从魂灯出发（失控为 0），先洞察，再用异能脉冲打中弱点 3 次，全程失控不满，打到约 30% 血时它停手，弹出认可 Toast（+30）
- [ ] 6. 守护者战：不洞察，或者失控被打满（比如连放 4 次以上异能脉冲），到 30% 时显示「仅此而已吗」，之后打到 0 只能拿到普通胜利（+10），Toast 显示「战斗胜利」而不是「守护者的认可」
- [ ] 7. 两场被打败都回到对应魂灯，能重打，不崩；胜或认可之后提示「第1章 完成」，重开游戏读档，结果还在

### Out（放 M2）
- 完整交涉树、多轮认可演算、`guardian_1_recognition = 3`
- 失控满值的真实后果（自伤、强制暴走、HP 上限下降、堕落分支）
- 防御 / 打断 / 状态异常，以及弱点以外的收益；守护者多阶段
- 精英战可选奖励 `echo_level += 1`、Beat12 之后的节拍、flag 存档 v2 结构

### 策划已确认的决定
1. **守护者位置**：在第3层殿堂（Beat11/12）。第2–3层的房间拆分放在关卡线那一刀。这一刀先把守护者门和殿前魂灯临时放在现有可玩房间的末端，方便 F5 直接验；关卡线做好后再挪到第3层，门和 flag 逻辑不变
2. **id 和 flag**：敌人 id 用 `death_knight`，flag 沿用 `elite_corpse_knight_defeated`；守护者结果 flag 叫 `guardian_1_result`
3. **认可档次**：M1 定为胜 = 1、认可 = 2，高 / 中 / 低留给 M2
4. **失控**：「未失控」= 本场失控值从未到 100。**魂灯存档时把失控值清零**（调用现有 `reset_overload()`），这样从殿前魂灯进门时失控固定是 0，认可条件对每个玩家都一样
5. **魂灯恢复**：**魂灯存档前回满 HP**（对齐 Beat05），败后读档就不会读到残血
6. **败的流程**：读单槽存档回到魂灯；没有存档时回满 HP 留在原地
7. **Toast 区分**：普通胜利的 Toast 改为「战斗胜利 · 认可 +N」；只有认可档弹「守护者的认可」。精英战、杂兵战同样用「战斗胜利」
8. **缺美术**：先用 bone_guard 剪影占位，美术图按 `enemy_death_knight_combat_idle_p1_00` / `_p2_00` / `enemy_undead_overlord_combat_idle_00` 覆盖
9. **数值**：140 / 160 HP、敌招伤害、50% / 30% 阈值、3 次弱点命中都是默认值，写在 json 里，F5 实测后再调

## 验收标准（可勾选）

| # | 标准 | 过线条件 |
|---|------|----------|
| 1 | 观感 | 非演示房；敌我/技能反馈肉眼可辨 |
| 2 | 界面 | 中文指令 + HP/共鸣/失控/敌情状态齐全 |
| 3 | 技能取舍 | ≥2 个主动技能（含异能）使用场景不同；失控有可见后果或预警 |
| 4 | 智斗 | 至少 1 场：`???` → 揭示弱点 → 打弱点收益可感知 |
| 5 | 精英 | 死骸骑士可击败；有简单阶段变化 |
| 6 | 守护者框架 | 可进可战可出结果（认可分档可占位） |
| 7 | 稳定 | 从进战到结算无崩；失败可回魂灯重来 |

**占位策略**：剪影/简 FX 可通过功能与智斗验收；真图过检后替换。功能过 ≠ 美术终稿。
