# M1 战斗目标与验收

> 版本：v1.0  
> 日期：2026-09-23

---

## 一句话目标

**将 VS 战斗脚手架升级为可体验的战斗原型**——有画面演出、有界面可读性、有技能取舍、有情报智斗钩子；在 M1 范围（第0章完整 + 第1章 Beat 01-12）内闭环。

---

## 背景：当前问题

当前战斗是 **VS 脚手架**，不是成品。用户反馈四点不满意：

| # | 问题 | 现状 |
|---|------|------|
| 1 | 画面演出 | 紫底占位、无立绘、无受击/异能特效 |
| 2 | 整体界面 | 临时 HUD、操作区布局粗糙、可读性差 |
| 3 | 技能太简单 | 仅「攻击」+「异能共鸣」，无取舍 |
| 4 | 缺少智斗内容 | 敌情全透明，无情报/弱点系统钩子 |

M1 战斗需 **按这四点改进**。

## In Scope（做）

### 1. 画面演出

- [ ] 战斗背景替换：去掉紫底演示感，使用场景化背景（墓穴/大厅）
- [ ] 战斗立绘：主角 + 敌人战斗姿态立绘（至少骷髅守卫、精英死骸骑士）
- [ ] 受击反馈：受击闪白/抖动 + 伤害数字飘字
- [ ] 异能 FX：「异能共鸣」技能释放特效（手腕纹路 + 能量波）

### 2. 界面优化

- [ ] 战斗 HUD 重构：HP/共鸣槽/失控条清晰可读
- [ ] 操作区重排：指令按钮布局合理、反馈明确
- [ ] 敌人信息面板：显示名称、HP、状态（情报解锁后显示弱点）

### 3. 技能扩展

- [ ] 技能数量：主角至少 2～3 个可用技能
- [ ] 技能取舍：不同技能有不同消耗/效果/适用场景
- [ ] 技能示例：
  - 「攻击」— 基础物理伤害
  - 「异能共鸣」— 高伤害，消耗共鸣槽，增加失控
  - 「观察」— 不造成伤害，解锁敌人情报/弱点
  - 「防御」— 减伤，回复少量共鸣槽（可选）

### 4. 情报/弱点系统（智斗钩子）

- [ ] 敌情初始状态：未遭遇敌人显示「???」
- [ ] 情报解锁途径：
  - 战斗中使用「观察」→ 解锁部分情报
  - 击败敌人 → 解锁完整情报
  - 环境文献收集 → 预解锁（可选）
- [ ] 弱点利用：情报解锁后可见弱点，针对弱点攻击有加成

## 验收表：对照用户四点

> 测试者逐项确认并勾选。全部通过方可视为 M1 战斗验收合格。

### 1. 画面演出

| 验收项 | 通过标准 | ✓ |
|--------|----------|---|
| 战斗背景 | 非紫底，有场景化背景 | ☐ |
| 战斗立绘 | 主角 + 至少 2 种敌人有战斗姿态立绘 | ☐ |
| 受击反馈 | 受击时有闪白/抖动 + 伤害飘字 | ☐ |
| 异能特效 | 「异能共鸣」释放时有可辨识特效 | ☐ |

### 2. 整体界面

| 验收项 | 通过标准 | ✓ |
|--------|----------|---|
| HUD 可读 | HP/共鸣槽/失控条数值清晰可读 | ☐ |
| 操作区 | 指令按钮布局合理，有点击/选中反馈 | ☐ |
| 敌人面板 | 显示敌人名称、HP、状态 | ☐ |

### 3. 技能取舍

| 验收项 | 通过标准 | ✓ |
|--------|----------|---|
| 技能数量 | 战斗中可选技能 ≥3 个 | ☐ |
| 技能差异 | 不同技能消耗/效果有明显区别 | ☐ |
| 战术选择 | 玩家需根据情况选择技能，非无脑按攻击 | ☐ |

### 4. 智斗内容

| 验收项 | 通过标准 | ✓ |
|--------|----------|---|
| 情报空白 | 未解锁敌人显示「???」或部分隐藏 | ☐ |
| 观察解锁 | 使用「观察」技能可解锁敌人情报 | ☐ |
| 弱点利用 | 情报解锁后可见弱点，弱点攻击有加成提示 | ☐ |

### 通过标准

- **全部 13 项勾选** → M1 战斗验收通过
- 任意项未通过 → 记录问题，修复后重测

## 不做清单（明确排除）

以下内容 **在 M1 战斗中明确不做**，避免范围蔓延：

1. **完整交涉系统**：守护者战 Beat 12 仅做「可进入战斗、可打出结果」，交涉分支/多结局不做
2. **技能升级/天赋树**：技能固定，无成长系统
3. **道具消耗品**：战斗中不可使用道具
4. **敌人 AI 复杂行为**：敌人按固定模式行动，无策略 AI
5. **战斗动画精细演出**：受击/技能有反馈即可，不追求电影级演出
6. **音效配乐**：可占位，不挡功能验收
