**连通图**（→ 为出口方向，[灯] = 魂灯）
```
ch0_ruins ─(崩塌后单向)→ ch0_hall[灯] ─层门→ ch1_f1_entrance[灯] ─西→ hall_a ──┐
                                                          └─东→ trap_corridor ─┴→ maze → relay[灯]
relay → hall_b → elite_hall(前区|战场) ─阶梯→ ch1_f2_passage ─阶梯→ ch1_f3_guardian_ante[灯] ─大门→ 守护者战
```

- **第2–3层压缩成 2 个房间（过渡房 + 殿前），殿堂不单独做探索房**。理由：① Beat09/10 只有 1 条线索和 1 个可选物品，没有新机制；② M1 要验证的是「完整单层循环」，第1层已经完整；③ 精英/守护者稿规定大门交互就直接开战，胜利后回探索并提示「第1章 完成」，殿堂只作为战斗背景出现；④ 三层都做全，瓦片和房间工作量要翻三倍。
- **迷宫和陷阱服务情报主钩**：死路尽头一定放情报（迷路有收获）；陷阱侧龛拿骨卫情报；分岔路先走哪边，决定遇到尘埃怨灵时手上有没有情报（节拍说的「分岔影响遭遇顺序」）。异能压制陷阱会 +20 失控，失控会带进下一场战斗，中继魂灯才清零，这就形成了一次资源取舍。
- **不做的内容**（Out 或节拍写了「如有」）：小地图 / 迷雾 / 地图标记、毒气（属于状态异常）、魂灯商店、情报页面 UI。「情报汇总」改成殿前石碑和拿到情报时的一行提示。
- **持久情报规则**：读到文献后写 `intel_<enemy_id> = true`，以后和这种杂兵开战时自动调用 `reveal_enemy_intel()`。**只对杂兵生效**。骑士和守护者的笔记只给文字提示，不预先揭示，避免和「换阶段后情报作废」以及「认可必须用过洞察」冲突。洞察本身仍然只在本场战斗内生效。

- `bone_guard` 建议数值：HP 45 / attack 10 / defense 2 / recognition_value 10 / element `physical`，直接用现有骨卫美术。它弱异能脉冲，正好配合第0章的异能觉醒教学。
- 情报空白教学（Beat02）特意用尘埃怨灵：玩家在第0章习惯了狂按异能脉冲，这里会看到灰色的「被克制」；洞察后才发现弱点是物理。这就是 M1 智斗主钩的第一课。
- 入口到中继之间，强制战斗不超过 3 场（A 路 1 场加迷宫 1 场，或 B 路 0 场加迷宫 2 场）；地刺每次 8 伤害，最多扣到剩 1 HP。败北回最近魂灯。
- 杂兵出招沿用现有的 5–12 随机伤害（精英/守护者 PR 里没有 `rotation` 的敌人走兜底逻辑）。

## 6. 策划已确认的决定（2026-09-29）

> 以下 9 条全部按本稿执行；第 7 条的教学演出定为 M1 收尾单独一刀（第5刀），不并进关卡线四刀。
1. **杂兵不刷新**：打赢后按「房间 + 节点」记入存档，避免刷认可点；败北读档后，存档之后打掉的杂兵会复活。
2. **新增 `bone_guard`（物理 → 弱暗影）**作为唯一新杂兵，第0章 Beat05 的「骷髅守卫」就用它；节拍里的 `enemy_skeleton_warrior_intel` 统一改名为 `intel_<enemy_id>`，Beat02 教学敌人改成 `dust_wraith`。
3. **持久情报只对杂兵生效**：读文献后开战自动揭示；骑士和守护者的笔记只给文字提示。
4. **异能压制陷阱的代价是失控 +20**，不扣共鸣。现在探索中不会回写共鸣，改成扣共鸣需要另加逻辑。
5. **第2–3层合并为 2 个房间**，殿堂只作为战斗背景，不做探索房。
6. **存档仍是 v1，只加字段**（`room_id` / `flags` / `cleared`），不升 v2（v2 在精英/守护者稿里是 Out）。工程已确认精英/守护者 PR 会带上存档顶层 `flags` 字典和 `set_flag` / `get_flag`（老存档按空字典处理），读档按 flag 恢复骑士和守护者门的隐藏状态，确认框也做成可复用的；所以第1刀只加 `room_id` 和 `cleared`，层门直接复用那个确认框。
7. **第0章 Beat05–08 的教学演出**（强制觉醒、教学覆盖层、`echo_level`）不在关卡线里。关卡线只负责摆敌人和写 flag；演出另开一刀，或者留到 M1 收尾。
8. 第0章 Beat01–03（外围废墟）放在第4刀；在那之前，新游戏从 `ch0_hall` 开始。
9. 第1层情报总数暂定 5 份（骨卫笔记、尘埃怨灵笔记、骑士遗书①②、探索区B 文献），大厅的 2 份碎片算第0章，不计入第1层。
