## 一、三幕结构总览

| 幕 | 章节范围 | 核心主题 | 玩家认知转变 |
|----|----------|----------|--------------|
| 序幕 | 第0章（外围） | 诱饵与误入 | 「这是什么地方？」→「我回不去了」 |
| 第一幕 | 第1～3章（1～5层） | 求生与觉醒 | 「我会死在这里」→「我能靠异能活下去」 |
| 第二幕 | 第4～6章（6～8层） | 变强与代价 | 「我越来越强」→「力量有失控的代价」 |
| 第三幕 | 第7章～终章（9～10层） | 真相与抉择 | 「我要见到真正的主人」→「我选择我的结局」 |
| 隐藏 | 宝物殿 | 最终试炼 | 高认可全收集解锁 |

## 三、阶段覆盖说明

### VS（垂直切片）覆盖范围
- **仅第0章教学房级切片**
- 内容：外围废墟入口 → 魂灯点燃 → 首次遭遇战（2只骷髅） → 异能共鸣教学 → 认可toast演示 → 通往第1层的门前截止
- 目的：验证核心手感（压迫感、异能翻盘、存档体验）

### M1 里程碑覆盖范围
- **第0章完整 + 第1章可玩段**
- 内容：VS全部 + 墓穴迷宫探索 + 陷阱机制 + 情报空白→解锁流程 + 精英战原型 + 第一守护者战斗框架
- 目的：验证完整单层循环（探索→战斗→情报→认可）

## 四、多结局钩子

| 结局 | 触发条件 | 关键分歧点 |
|------|----------|-----------|
| **认可结局**（正常好结局） | 认可点≥阈值；失控条<50%；完成赌约 | 第6章取舍抉择；终章赌约选项 |
| **惨胜结局** | 认可点中等；失控条50-80%；强行通关 | 第3章决斗选择；第5章假情报应对 |
| **堕落结局** | 失控条≥80%或关键堕落选项 | 第4章精神崩溃；第6章牺牲选项 |
| **隐藏结局** | 认可点MAX；全守护者好感；宝物殿通关 | 全章节支线完成；情报全收集 |
