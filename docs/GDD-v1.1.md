## 1. 愿景与目标用户

### 1.1 愿景一句话
误入神话级要塞的冒险者，用凡人的胆量与超常异能，一层层赢得守护者的「认可」，最终被主人亲自承认。

### 1.2 体验支柱（3）
1. **误入压迫感**  
2. **异能翻盘感**（共鸣 + 情报 + 地形）  
3. **认可成长感**（认可为主货币）

### 1.3 目标用户
剧情驱动回合 RPG / 轻度策略玩家；原作粉吃彩蛋，路人能通关。

### 1.4 产品形态（假设）
单机买断；PC（Steam）首发；同人阶段明确，商业前授权或致敬化。

## 2. 叙事骨架

### 2.1 既定事实
- 背景借用纳萨力克大坟墓设定（同人）。  
- 玩家是误入的冒险家，拥有惊人能力。  
- 弧线：闯入最底层并获得认可。

### 2.2 叙事解释（假设）
主人对「异世界是否存在值得承认的强者」好奇；防御出现可控缝隙，主角因异能被标记为特殊样本而「误入」。全程半默许试炼。

### 2.3 三幕
| 幕 | 范围 | 玩家认知 | 实际 |
|----|------|----------|------|
| 0 | 外围～入口 | 寻宝/迷路 | 诱饵与误入 |
| 1 | 1～5 层 | 硬闯求生 | 学会情报/异能/认可 |
| 2 | 6～8 层 | 变强 | 认真对待；失控代价 |
| 3 | 9～10 层 | 见真正的王 | 赌约与多结局 |

### 2.4 结局（3+1）
认可 / 惨胜 / 堕落 / 隐藏（高认可全收集 + 宝物殿）。

## 3. 类型（已锁定）

**纯回合制箱庭 RPG。** 探索与守护者战统一指令回合（前后排/站位条）；不做独立格子战场。视角仍建议 2.5D（待拍板）。分级建议 16+。

## 4. 核心循环与系统

### 4.1 单层循环
进入层 → 探索 → 遭遇战 → 关键节点 → 阶层试炼 → 结算认可与异能成长 → 层门。

### 4.2 异能系统
| 子系统 | 需求 |
|--------|------|
| 异能槽 | 战斗消耗「共鸣」；探索可破特定机关 |
| 共鸣获取 | 精英、文献、环境伤害、守护者认可 |
| 失控条 | 过度使用推高；满则负面/堕落线 |
| 形态成长 | 每层试炼解锁 1 个规则级异能 |
| 红线 | 不能直接秒最终存在；终局靠赌约与选择 |

代码占位：Deep Echo = 异能共鸣技能；Overload = 失控。

### 4.3 队伍
可 1～2 人开场；至多 3 可控 + 2 援护。属性含 HP、资源、精神压力、层环境条。

### 4.4 战斗
指令：攻击/技能/异能/道具/防御/换位。情报解锁弱点；可有假情报；BOSS 出现认可窗口（交涉/停手/赌约）。

### 4.5 箱庭
每层独立箱庭；非开放世界；魂灯存档；已通层快旅。

### 4.6 认可经济
试炼评价 S/A/B、支线选择、文献集齐 → 解锁援护/异能节点/结局权重。金币为辅。

## 5. 关卡记忆点

## 7. 工程接口
引擎：**Godot 4（已选定）**。表驱动 JSON。存档分：层进度 / 认可 / 情报 / 失控。

### 7.2 实现序（纯回合）
1. 箱庭移动/交互/存档点  
2. 回合战斗最小集  
3. 情报 UI  
4. 异能槽 + 失控条  
5. 认可结算  
6. 对话抉择与结局 flag  

> ~~BOSS 格子战插件~~ 已删除，禁止回弹。

### 7.3 M1 验收
- 外围误入到第 1 层一段可跑通  
- 精英战 + 压力 BOSS 原型  
- 异能≥2，失控可见  
- 情报从空白到解锁可感知  
- 问卷压迫/翻盘 ≥70% 正向
