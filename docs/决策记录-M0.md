## 已锁定决策

### 1. 视角：2.5D

- **结论**：俯视箱庭探索 + 立绘对话
- **理由**：平衡开发成本与视觉表现；符合回合制箱庭 RPG 的惯用视角

### 2. 分级：16+ 弱化

- **结论**：接受 16+ 内容定位，配合适度弱化处理
- **理由**：保留暗黑氛围，同时避免过度血腥/恐怖导致受众收窄或审核风险

### 3. IP 路径：纯同人自用

- **结论**：现阶段定位为同人作品，仅供个人学习与创作使用，不对外商业发行承诺
- **补充**：仅借鉴氛围，角色设计原创；如未来商业化需另行获取授权或致敬化处理

### 4. 局内美术锁定：像素 + SpriteFrames 逐帧

- **结论**：
  - 局内美术：**仅限像素风格**（瓦片 32×32，角色 64×64）
  - 概念图 / Grok 氛围图：**仅供参考**，禁止作为正式素材入库
  - VS 动画：**SpriteFrames 逐帧**（idle/walk/attack），禁止骨骼绑定或高清 HD 动画
- **理由**：
  1. VS 成本可控：逐帧像素动画生产周期短、迭代快，适合小团队 M1 阶段
  2. 现有导入管线统一：Godot 已配置 filter=false/mipmaps=false 像素导入规范，无需额外骨骼/HD 管线
- **下一步负责方**：
  | 负责方 | 任务 |
  |--------|------|
  | 美术 | 补充动画帧数表（idle 4f / walk 6f / attack 4f 基准）；禁止概念图直接入仓 |
  | 工程 | 完善 SpriteFrames 导入规范文档；更新 flag 表标注动画状态机字段 |
