## 二、外形关键词（原创设计）

### 整体风格
- **基调**：普通人外表 + 异能觉醒后的视觉变化
- **服装**：破旧皮甲 + 灰色斗篷 + 简易背包（冒险者标配）
- **特征**：左手腕有淡淡的异能纹路（觉醒后会发光）

### 配色建议
| 部位 | 常态 | 异能激活态 |
|------|------|-----------|
| 瞳色 | 灰蓝色 | 金色光芒（deep_echo激活） |
| 异能纹路 | 淡灰（几乎不可见） | 青金色流动纹路 |
| 气场 | 无 | power-ash色调光晕 |
| 失控态 | — | overload-purple侵蚀纹路 |

### 禁止设计
- 不使用任何IP角色的标志性特征
- 不使用骷髅面具、死灵法师长袍等已知角色元素
- 保持「普通冒险者」的基础辨识度

## 三、背景设定

### 误入原因（表层）
- 跟随冒险者公会的「高薪委托」前往废墟探索
- 队伍遭遇袭击，独自逃入未知洞穴
- 发现入口消失，被困于深墓之中

### 误入原因（真相·可后期揭示）
- 主人对「异世界是否存在值得承认的强者」好奇
- 深墓的防御出现「可控缝隙」
- 主角因体内沉睡的异能被标记为「特殊样本」
- 实际为半默许的试炼邀请

## 四、异能系统

### 异能表象
| 阶段 | 表现 | 触发条件 |
|------|------|----------|
| 沉睡 | 无任何异常 | 游戏开始前 |
| 觉醒 | 危机时本能释放防护/反击 | 第0章首次战斗 |
| 共鸣 | 可主动使用，消耗共鸣槽 | 获得首个deep_echo技能后 |
| 爆发 | 规则级效果，改变战斗局势 | 守护者认可后解锁 |
| 失控 | 强制高伤害+自伤+负面状态 | 失控条满 |

### 异能风格
- **视觉**：青金色能量流（非火焰/冰霜/雷电等常见元素）
- **质感**：像液态金属在皮肤下流动
- **音效**：低沉的嗡鸣+玻璃碎裂声

### 失控代价
- 每次失控后：HP上限临时降低、精神压力条增加
- 累计失控：解锁堕落结局分支
- 最终失控：不可逆的负面结局锁定

## 五、性格三词

1. **倔强** — 被困也不放弃，被打倒也要站起来
2. **好奇** — 对深墓的秘密有探索欲，不只是想逃出去
3. **共情** — 能理解守护者的立场，这是获得认可的关键

### 性格禁区
- 不是热血笨蛋（有基本智商）
- 不是冷酷无情（会对NPC产生情感连接）
- 不是圣母（能做出艰难抉择）

---

## 六、玩家幻想

### 核心幻想
> 「我是被命运选中的普通人，用觉醒的力量以弱胜强，最终被真正的强者看见并承认。」

### 幻想拆解
| 幻想点 | 游戏实现 |
|--------|----------|
| 以弱胜强 | 初始数值低，但异能技能可逆转战局 |
| 被看见 | 守护者从轻视→认真对待→认可的态度转变 |
| 成长可感 | 每章解锁新异能形态，数值+技能双成长 |
| 选择有意义 | 对话选项影响认可值和结局分支 |

## 七、队友关系位

### 设计预留（可1-2人后补）

| 位置 | 建议类型 | 关系定位 | 加入时机 |
|------|----------|----------|----------|
| 队友A | 前排战士/坦克 | 可靠的后盾，互补型 | 第1章末或第2章初 |

- 队友有独立认可线（可选支线）

## 九、给工程的 flag 暗示

### 核心状态变量

```
# 异能等级（0-5，每获得守护者认可+1）
player.echo_level: int = 0

# 失控累计值（0-100，满则触发失控）
player.overload_gauge: int = 0

# 累计失控次数（影响结局权重）
player.overload_count: int = 0

# 认可总点数
player.recognition_total: int = 0

# 各守护者认可状态（字典）
player.guardian_recognition: dict = {
    "floor_1": 0,  # -1=敌对, 0=未接触, 1=认可
    "floor_2": 0,
    # ... floor_3 ~ floor_7
    "final": 0
}

# 结局权重（运行时计算）
player.ending_weight: dict = {
    "recognition": 0,   # 认可结局权重
    "pyrrhic": 0,       # 惨胜结局权重
    "corruption": 0,    # 堕落结局权重
    "hidden": 0         # 隐藏结局权重
}

# 关键剧情flag
player.story_flags: dict = {
    "first_echo_awakened": false,      # 首次异能觉醒
    "first_overload": false,           # 首次失控
    "first_recognition": false,        # 首次获得认可
    "met_guardian_1": false,           # 遇见第一守护者
    # ... 更多flag按需添加
}
```

### Flag 命名规范
- 布尔flag：`has_xxx` / `is_xxx` / `met_xxx`
- 数值flag：`xxx_level` / `xxx_count` / `xxx_gauge`
- 时间flag：`xxx_timestamp`（如需记录发生时间）
