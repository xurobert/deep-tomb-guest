# 像素美术生产管线

> 状态：**已锁定**  
> 锁定日期：2026-09-10  
> 适用范围：所有局内像素美术资产

本文档定义从 AI 生成图到最终像素资产的完整生产管线。

---

## 🔒 画布尺寸锁定

| 资产类型 | 画布尺寸 | 说明 |
|----------|----------|------|
| 角色精灵 (character) | **64×64 px** | 玩家、敌人、NPC |
| 地图瓦片 (tile) | **32×32 px** | 地面、墙壁、装饰 |
| 特效 (fx) | **64×64 px** | 技能特效、状态特效 |
| 环境物件 (prop) | **64×64 或 32×64 px** | 魂灯、宝箱等 |

---

## 生产管线流程

```
┌─────────────────────────────────────────────────────────────────┐
│  1. Grok / AI 生成                                               │
│     └─ 输入：提示词（见 prompt-sheet-vs-ch0.md）                  │
│     └─ 输出：高分辨率概念图（通常 512×512 或更大）                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  2. Nearest-neighbor 缩放                                        │
│     └─ 角色：缩放至 **精确 64×64 像素**                           │
│     └─ 瓦片：缩放至 **精确 32×32 像素**                           │
│     └─ ⚠️ 必须使用 Nearest-neighbor（最近邻）插值                 │
│     └─ ❌ 禁止使用 Bilinear / Bicubic 等平滑插值                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  3. 调色板量化                                                    │
│     └─ 量化至锁定调色板（见 palette-lock.md）                     │
│     └─ 核心色：stone-black #1A1C22, teal-stone #3A4A52,          │
│                bone-white #D8D0C4, gilt-gold #C9A24A,            │
│                blood-red #8B1E2D, power-ash #7A8B9A,             │
│                overload-purple #6B3FA0, readable-green #4A7C59   │
│     └─ 建议 ≤16 色                                                │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  4. 质量检查 — 「糊不糊」判定                                      │
│     └─ ✅ 通过：边缘干净硬朗、像素颗粒感清晰、剪影可辨             │
│     └─ ❌ 失败：边缘模糊、渐变羽化、亚像素细节、看起来「糊」       │
│     └─ 若失败：返回步骤 1 重新生成或手动修图                       │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  5. 人工审核                                                      │
│     └─ 检查项：                                                   │
│        - [ ] 尺寸正确（64×64 或 32×32）                           │
│        - [ ] 调色板符合锁定色值                                    │
│        - [ ] 无模糊/抗锯齿                                         │
│        - [ ] 锚点符合规范（角色底部中心）                          │
│        - [ ] 命名符合规范                                          │
│     └─ 审核通过后方可进入下一步                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  6. 提交入库                                                      │
│     └─ 最终像素资产 → `assets/art/` 目录                          │
│     └─ Godot 导入设置：Filter OFF, Mipmaps OFF                    │
└─────────────────────────────────────────────────────────────────┘
```

## 参考图存放规范

### 允许位置

| 内容 | 存放位置 | 说明 |
|------|----------|------|
| AI 生成参考图 | `docs/art/ref/grok/` | 标注「非进仓」|
| 概念草图 | `docs/art/ref/concept/` | 标注「非进仓」|
| 外部参考 | `docs/art/ref/external/` | 需注明来源 |
| 大尺寸概念图 | `docs/art/ref/` | 标注「非进仓」|

### 🔒 严禁行为

| 行为 | 状态 |
|------|------|
| 将 AI 生成图直接放入 `assets/` | ❌ **禁止** |
| 将未经缩放/量化的图片作为游戏资产 | ❌ **禁止** |
| 将「糊」的图片强行入库 | ❌ **禁止** |
| 概念图不标注「非进仓」 | ❌ **禁止** |

### 标注要求

所有参考图/概念图必须在文件名或引用处标注「非进仓」：

```
hero_concept_grok_ref.png           # AI 生成参考（非进仓）
skeleton_guard_concept_ref.png      # 概念草图（非进仓）
```

在文档中引用参考图时：

```markdown
> ⚠️ 以下图片仅供参考，非最终游戏资产（非进仓）
```

## 工具建议

### 缩放工具

| 工具 | 设置 |
|------|------|
| Aseprite | Sprite > Sprite Size > Method: Nearest Neighbor |
| Photoshop | Image > Image Size > Resample: Nearest Neighbor |
| GIMP | Image > Scale Image > Interpolation: None |
| ImageMagick | `convert input.png -filter point -resize 64x64 output.png` |

### 调色板量化工具

| 工具 | 说明 |
|------|------|
| Aseprite | Sprite > Color Mode > Indexed，导入自定义调色板 |
| Photoshop | Image > Mode > Indexed Color |
| GIMP | Image > Mode > Indexed |

## 「糊不糊」判定标准

### ✅ 通过标准

- 像素边缘清晰，无模糊过渡
- 每个像素颜色来自锁定调色板
- 在 1:1 放大后仍可辨识剪影
- 无渐变色带、无抗锯齿痕迹

### ❌ 失败标准

- 边缘存在中间色调/羽化
- 存在非调色板颜色
- 放大后细节模糊不清
- 「看起来像缩小的高清图」而非「真正的像素画」

### 失败后处理

1. **轻微问题**：手动用调色板颜色逐像素修正边缘
2. **严重问题**：返回步骤 1，调整提示词重新生成
3. **无法挽救**：放弃该图，改用其他参考或从零手绘
