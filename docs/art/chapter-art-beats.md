# 各章节美术节拍表

本文档列出各章节的核心美术节点，供美术资产制作与生成提示词参考。

> **术语约定**：异能共鸣 = Deep Echo / 失控 = Overload / 认可 = Recognition  
> **风格锁定**：2.5D 俯视箱庭 + 立绘肖像；16+ 暗调；纯原创同人（角色造型原创，避免任何官方肖像——守护者使用职能名如「死者统领」）

---

## 第 0 章：诱饵误入（外围 → 入口）

**场景色温**：石底 `#1A1C22` 主导，石青 `#3A4A52` 过渡，骨白 `#D8D0C4` 高光点缀

### 节拍概览

| Beat | 事件描述 | 美术重点 |
|------|----------|----------|
| 01 | 野外夜景，玩家靠近古墓外围 | 环境：枯树 + 破碎石碑；远景坟墓剪影 |
| 02 | 发现入口阶梯，诱饵光源 | 鎏金 `#C9A24A` 微光从裂缝透出 |
| 03 | 踏入墓道门厅 | 石质走廊；魂灯首次出现（存档点） |
| 04 | 骷髅守卫遭遇战 | 敌人：骷髅兵剪影 + 攻击特效 |
| 05 | 获取首件情报文献 | UI：情报弹窗 + 骨白碑文样式 |
| 06 | 走廊陷阱触发 | 地刺/落石特效；血曜 `#8B1E2D` 伤害提示 |
| 07 | 异能共鸣首次觉醒 | VFX：power-ash `#7A8B9A` 光环；UI 共鸣槽首现 |
| 08 | 抵达第一层门前 | 场景过渡：层门 + 守护者虚影预告 |

### 立绘首登

- **玩家角色**：冒险者战斗立绘（胸像）
- **魂灯 NPC**（如有对话）：可用抽象光球代替

### 禁忌画面（16+ 限制）

- 伤害表现仅用闪红/屏幕震动，无断肢喷血
- 骷髅敌人需去写实内脏，保持风格化骨骼轮廓
