# 美术方向锁定

> 状态：**已锁定**  
> 锁定日期：2026-09-10

本文档记录项目美术方向的三项核心锁定决策。

---

## 决策区块

### 🔒 锁定 1：视角

| 项 | 值 |
|----|-----|
| 视角类型 | **2.5D 俯视箱庭** |
| 探索/战斗 | 俯视正交像素地图 |
| 对话 | 日系立绘叠加 |
| 禁止 | 3D 建模、透视摄像机、自由旋转 |

详细规范见 [perspective-and-pipeline.md](perspective-and-pipeline.md)。

---

### 🔒 锁定 2：分级 16+ 弱化

| 项 | 值 |
|----|-----|
| 目标分级 | **16+（青年向）** |
| 内容尺度 | 暗黑氛围允许，但需弱化处理 |
| 血腥表现 | 少血腥特写、暗示代替直给 |
| 暴力表现 | 战斗伤害以数值/特效为主，不做肢解/内脏等细节 |
| 性暗示 | 极简或无 |
| 语言 | 允许轻度脏话，无极端侮辱 |

#### 弱化原则

1. **暗示代替直给**：恐怖/血腥场景通过音效、台词暗示、屏幕震动、遮挡等间接表现，不做高清特写。
2. **氛围优先**：保持深墓的压迫感和黑暗哥特风，但不以猎奇为目的。
3. **情绪安全阀**：关键剧情后可设计「缓冲」场景，避免连续重压。

---

### 🔒 锁定 3：IP 纯同人自用

| 项 | 值 |
|----|-----|
| 性质 | **纯同人 / 粉丝创作（同人自用）** |
| 来源 | 只借「深墓 / 大坟墓」氛围设定 |
| 角色 | **原创角色造型**，不描摹官方立绘 |
| 官方设定 | **不宣称为官方设定**，不使用官方人物名 |
| 发行 | 商业发行前须获授权或完成致敬化改造 |

#### IP 红线

- ❌ 直接复制/描摹 OVERLORD 官方角色立绘
- ❌ 宣称本作为「官方游戏」或「官方授权」
- ❌ 使用官方角色原名（如需致敬可用谐音/暗示）
- ❌ 大规模公开商业发行（当前阶段）

#### 允许范围

- ✅ 借用「深墓」「层级」「守护者」等通用概念
- ✅ 黑暗哥特氛围、地下城探索结构
- ✅ 原创主角、原创敌人、原创 NPC 造型
- ✅ 个人/小圈子学习交流分享
