# 锁定调色板

本文档定义《深墓来客》的核心色彩系统，所有美术资产必须遵循此调色板。

## 色彩角色表

| 角色 | 英文 ID | 色值 | 用途说明 |
|------|---------|------|----------|
| 石底 | stone | `#1A1C22` | 场景基底、深层阴影 |
| 石青 | teal-stone | `#3A4A52` | 石材中间调、环境过渡 |
| 骨白 | bone | `#D8D0C4` | 骨骼、碑文、高光 |
| 鎏金 | gilt | `#C9A24A` | 装饰纹样、重要交互提示 |
| 血曜 | blood | `#8B1E2D` | 危险、伤害、敌意标识 |
| 异能灰光 | power-ash | `#7A8B9A` | 显示：异能共鸣 / code id: Deep Echo |
| 失控紫 | overload-purple | `#6B3FA0` | 显示：失控 / code id: Overload |
| 可读绿 | readable-green | `#4A7C59` | 正向反馈、可交互物高亮 |

## 风格支柱

### 角色与敌人
- **暗黑哥特线稿**：强调轮廓与结构的线描风格
- **日系立绘读形**：保证剪影辨识度，确保缩小后仍可读

### UI 风格
- 石碑灰 (`#1A1C22` / `#3A4A52`) 作为面板底色
- 鎏金 (`#C9A24A`) 用于边框与重点文字

### 场景用色
- 按景深层级调整色温
- 近景偏暖（骨白、鎏金点缀）
- 远景偏冷（石青、石底沉淀）
