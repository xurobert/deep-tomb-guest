# 术语对照表

本表列出代码中使用的英文标识符与游戏内中文显示名称的对照关系。

## 核心术语

| 代码 id / 英文占位 | 中文显示名 |
|-------------------|-----------|
| deep_echo / Deep Echo | 异能共鸣 |
| overload / Overload | 失控 |
| recognition / Recognition | 认可 |
| recognition_toast | 认可提示 |
| save crystal / save_point | 魂灯（存档点） |
| box RPG / exploration | 箱庭探索 |

## 补充说明

- **共鸣**：异能资源，对应代码中的 `deep_echo` 相关系统
- **认可点**：主成长货币，对应代码中的 `recognition` 系统
