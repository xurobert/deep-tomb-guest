# 第1刀「层门」：探索瓦片 / 层门 / 文本框美术（ch0_hall）

全部是 Pillow 逐像素手绘（没有生图工具可用，也符合 `naming-and-import.md` 里「assets/ 只放手绘像素」的规定）。
RGBA，alpha 只有 0/255，无抗锯齿，颜色只用 16 色锁定色盘。可复现脚本在 `stage/level_s1/tools/`（`make_assets.py` 负责出图，`review.py` 负责出审阅图，`verify.py` 负责校验）。

目录结构和仓库 `assets/art/` 一一对应，拷过去就能用。

## 导入设置（所有文件）

| 设置项 | 值 |
|---|---|
| Filter | **Nearest**（关） |
| Mipmaps | **关** |
| Compress | Lossless |
| Repeat | Disabled（TileMap 不需要开） |

## 文件清单

### tiles/floor/（32×32，不透明，可无缝平铺）

| 文件 | 用途 |
|---|---|
| `tile_floor_stone_00.png` | 基础石板地面（深 #1A1C22 石面，#000000 缝，#3A4A52 边缘磨亮） |
| `tile_floor_stone_01.png` | 变体：中间那块石板一分为二，另有两道裂纹 |
| `tile_floor_stone_02.png` | 变体：换一种分块，石缝里长了两小撮苔藓 |

- 三块砖外圈 2px 完全相同，所以可以任意混铺，不会出现接缝。建议比例：00 约 78%、01 约 12%、02 约 10%，随机散布（审阅图就是这个比例）。
- 地面刻意压暗、压低对比，比主角和骨卫暗一档，让 64×64 角色能从地面上跳出来。

### tiles/deco/（透明底，叠在别的瓦片上面）

| 文件 | 尺寸 | 用途 / 放法 |
|---|---|---|
| `tile_deco_lectern.png` | 32×32 | 文献台（情报碎片 1）。石座上的斜面台放着一本摊开的书，垂下一根金色书签带，柱身上嵌一个小小的金色符文，用来提示「可交互」。放在地面格上，自带黑色接地阴影 |
| `tile_deco_mural_00.png` | 64×32 | 壁画（情报碎片 2）：一面褪色浮雕，画的是层层往下收窄的深墓，最底层有一点紫光，暗示石门会回应异能。对齐到北墙的两格上（y 与北墙瓦片相同）；上面 7px 透明，让墙顶露出来，浮雕只盖住砖面 |

- **火把帧序**：`00 → 01` 循环，建议 **6 fps**。两个火把可以错开半个周期（其中一个从 01 开始播），显得更自然。支架在两帧里完全相同（verify 已检查）。火把放在北墙格上，火焰会盖住一部分墙顶。

### tiles/interactive/（64×64，透明底）

| 文件 | 用途 |
|---|---|
| `tile_gate_floor_closed.png` | 层门关闭：两根石柱、刻着符文的门楣、两扇石门板，中间是一个封印圆环（倒三角加一只眼），带一点暗青色 |
| `tile_gate_floor_open_00.png` | 开门第 1 帧：封印和石柱上的符文亮成紫色 #6B3FA0，门缝裂出一道紫光（「石门回应异能」） |
| `tile_gate_floor_open_01.png` | 开门第 2 帧：两扇门板往两侧滑进石柱里一半，露出往下走的台阶 |
| `tile_gate_floor_open_02.png` | 开门第 3 帧（停在这一帧）：门板完全收进去，露出一条往下的黑暗阶梯，深处有几点紫光 |

- **放法**：占 2×2 格，左上角对齐北墙那一行（例如第 9–10 列、第 0–1 行）。上半部分（门楣）的顶和北墙墙顶齐平，下半部分（门板和门槛）立在第 1 行地面上。第 1 行这两格要做成实心，玩家站在第 2 行按 [E]。
- 门槛两侧最下面 6 行左右是透明的，可以透出底下的地面，所以下面照常铺地面瓦片。
- **帧序**：`closed`（静态） → 确认后播 `open_00 → open_01 → open_02`，建议 **8 fps**，不循环，停在 `open_02`；然后淡出切房。如果想让「异能回应」多停一会儿，可以让 `open_00` 多停 2 帧。
- 已开门的存档：直接显示 `open_02`。
- 门楣和石柱在四帧里位置完全一样，只有门板、封印和符文的颜色在变。
